# Services Http Livewire

## Preview files and reuse published archives without duplicating storage
File GET responses preview inline or on a safe escaped preview page by default; download=1 explicitly downloads. PreviewFileResponse adapts Livewire download effects into file-preview events consumed by resources/js/file-preview.js. Preserve endpoint authorization. Public content attachments may reference a ReportVerification id and SHA-256 instead of an upload path: select only active-school, approved Biasa documents within management scope; recheck status/hash on public access and never delete the archive when detaching.
